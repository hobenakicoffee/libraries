# Visibility

Constants for public and private visibility settings.

## Usage

```ts
import { Visibility } from "@hobenakicoffee/libraries/constants";
```

## Values

| Constant | Value | Type |
| ------- | ----- | ---- |
| `Visibility.PUBLIC` | `"public"` | `Visibility` |
| `Visibility.PRIVATE` | `"private"` | `Visibility` |

## Type

```ts
type Visibility = "public" | "private";
```

## Example

```ts
const isPublic = Visibility.PUBLIC;
// => "public"

const isPrivate = Visibility.PRIVATE;
// => "private"
```
